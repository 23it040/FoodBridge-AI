# ⚠️ System Error & Offline Page Specifications (`/404`, `/500`, `/401`, `/403`, `/offline`)

> **Location**: `frontend/src/pages/Error/`

---

## 📐 Screen Breakdown in Figma

- **`404` Page Not Found (`NotFoundPage.jsx`)**: Centered 404 Illustration, text *"Oops! The page you are looking for does not exist."*, `"Back to Home"` primary button.
- **`500` Internal Error (`InternalErrorPage.jsx`)**: System error alert card, `"Reload Page"` button.
- **`401` Unauthorized (`UnauthorizedPage.jsx`)**: `"Please sign in to access this page"`, `"Go to Login"` button.
- **`403` Forbidden (`ForbiddenPage.jsx`)**: `"You do not have permission to view this section"`.
- **`Offline` (`OfflinePage.jsx`)**: Network status alert banner *"No internet connection detected."*
