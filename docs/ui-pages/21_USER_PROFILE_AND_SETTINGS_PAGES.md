# 👤 User Profile & Settings Specifications (`/profile`, `/profile/edit`, `/profile/change-password`, `/settings`)

> **Files**: `frontend/src/pages/Profile/ProfileView.jsx`, `EditProfile.jsx`, `ChangePassword.jsx`, `Settings.jsx`

---

## 📐 Screen Breakdown in Figma

1. **Profile View (`/profile`)**:
   - User Account Card with Role Badge, Joined Date, Contact Details, Organization Info.
2. **Edit Profile (`/profile/edit`)**:
   - Profile Form: Name, Phone Number, Organization Logo Upload, Street Address, GPS Location Picker.
3. **Change Password (`/profile/change-password`)**:
   - Password Form: Current Password, New Password, Confirm New Password.
4. **Settings (`/settings`)**:
   - Toggles: Email Notifications, SMS Pickup Alerts, Marketing Preferences.
